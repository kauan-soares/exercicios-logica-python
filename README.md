# Exercícios de Lógica de Programação em Python 

Repositório dedicado ao armazenamento e evolução de scripts desenvolvidos durante os meus estudos de lógica de programação e algoritmos com Python.

##  Projetos Incluídos

* **`cadastro-alunos.py`**: Sistema de registo de utilizadores com validação de entradas e armazenamento em listas de dicionários.
* **`sistema-de-descontos.py`**: Algoritmo para cálculo de frete proporcional e aplicação de regras condicionais.
* **`sistema-de-vendas.py`**: Aplicação CLI completa que integra gestão de clientes, registo de vendas com desconto/cupão e emissão de relatórios gerais.

## Tecnologias Utilizadas

* Python 3
* Git & GitHub
